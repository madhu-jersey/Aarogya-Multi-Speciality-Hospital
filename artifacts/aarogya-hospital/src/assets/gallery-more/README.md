# Extra gallery photos

Every image in this folder appears behind the **View more photos** button in the gallery, and in the full-screen viewer after the four main photos.

- Supported: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
- Order follows the file name, so name them `01.jpg`, `02.jpg`, … to control it.
- The button stays hidden while this folder has no photos.
- Keep each photo small (about 1600 px wide, WebP or JPEG under 300 KB). Full-size phone photos are several MB each and slow the page on phones.
